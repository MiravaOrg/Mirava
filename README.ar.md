## نظرة عامة

Mirava هو مشروع يجمع مرايا البرمجيات ومستودعات الحزم لتوفير وصول سريع ومستقر، خصوصًا للمستخدمين داخل إيران. ملف `README.md` الإنجليزي هو الوثيقة الأساسية، وهذه النسخة تشرح الواجهة والاستخدام الجديدين بالعربية.

## الميزات الرئيسية

- اكتشاف توزيعة Linux ومدير الحزم تلقائيًا
- التحقق من بيانات المستودع الفعلية قبل القياس
- ترتيب المرايا حسب سرعة النقل وTTFB بالتوازي
- قياس وإدارة خوادم DNS المحلية والعالمية
- نسخ احتياطية واسترجاع آمن للتغييرات المدعومة
- Doctor ومعلومات النظام والشبكة وأوامر غير تفاعلية
- لا حاجة إلى `yq` أو PyYAML وقت التشغيل

## فهرس المرايا وDNS

المصدر الأساسي لقائمة المرايا وDNS هو [`mirrors_list.yaml`](mirrors_list.yaml). لتجنب اختلاف الترجمات، تبقى الجداول الكاملة في README الإنجليزي وملف YAML.

## 🚀 الاستخدام

### تشغيل موصى به

```bash
git clone https://github.com/MiravaOrg/Mirava.git
cd Mirava
chmod +x check_mirrors.sh
./check_mirrors.sh
```

عند تشغيل `./check_mirrors.sh` بدون معاملات داخل طرفية تفاعلية تُفتح القائمة تلقائيًا. في الوضع غير التفاعلي ينتقل التنفيذ إلى فحص جميع المرايا.

### القائمة التفاعلية

| Key | Action | Description |
| ---: | --- | --- |
| `1` | تحسين مستودع هذا النظام | يكتشف التوزيعة ومدير الحزم، يتحقق من المرايا المتوافقة ويقيسها ثم يرتبها، ويمكنه تطبيق الأسرع بعد التأكيد. |
| `2` | البحث عن أسرع مرآة لحزمة/مستودع | تختار نوع الحزمة، ثم يتحقق Mirava من المرايا المرشحة ويقيسها. إذا طابق النوع مستودع النظام، يمكن عرض خيار التطبيق. |
| `3` | فحص كل المرايا والحزم | يفحص جميع النقاط المسجلة بالتوازي ويعرض النتائج والتقدم. |
| `4` | قياس وإدارة DNS | يفتح قائمة Local/Global/All، عرض DNS الحالي، تطبيق الزوج الأسرع اختياريًا، وإعادة الضبط. |
| `5` | عرض DNS الحالي | يعرض خوادم DNS الحالية دون تغييرها. |
| `6` | نظرة عامة على الخادم/الشبكة | يعرض اسم الجهاز والذاكرة ووقت التشغيل والنظام والمعمارية وIP العام والموقع عند توفره وDNS والمستودعات. |
| `7` | عرض Backend المكتشف | يعرض النظام والإصدار وcodename ومدير الحزم وعائلة المستودع ودعم التطبيق التلقائي. |
| `8` | عرض أنواع الحزم المدعومة | يعرض الأنواع الموجودة في ملف YAML. |
| `9` | Doctor / التحقق من البيانات | يتحقق من أوامر التشغيل وPython والـ backend وبيانات YAML وطريقة الصلاحيات. |
| `0` | خروج | يغلق القائمة. |

### قائمة DNS الفرعية

| Key | Action |
| ---: | --- |
| `1` | أسرع DNS إيراني/محلي |
| `2` | أسرع DNS عالمي |
| `3` | أسرع DNS من كل الإدخالات |
| `4` | عرض DNS الحالي |
| `5` | إعادة ضبط تغييرات DNS التي يديرها Mirava |
| `0` | رجوع |

### أوامر CLI

```bash
./check_mirrors.sh --menu
./check_mirrors.sh --system-repo
./check_mirrors.sh --apply-system-repo --yes
./check_mirrors.sh --check-all
./check_mirrors.sh --fastest Ubuntu
./check_mirrors.sh --fastest-ubuntu
./check_mirrors.sh --dns local
./check_mirrors.sh --dns global
./check_mirrors.sh --dns all
./check_mirrors.sh --current-dns
./check_mirrors.sh --system-info
./check_mirrors.sh --backend-info
./check_mirrors.sh --doctor
./check_mirrors.sh --list-packages
./check_mirrors.sh --help
```

## الأنظمة المدعومة

يدعم التطبيق التلقائي: Ubuntu/Debian عبر APT، وFedora/Rocky/AlmaLinux/CentOS عبر DNF/YUM، وArch/Manjaro عبر Pacman، وAlpine عبر APK، وopenSUSE عبر Zypper. يمكن قياس بعض التوزيعات المشتقة، لكن Mirava يتجنب تعديل إعداداتها تلقائيًا إذا لم يكن التخطيط معروفًا بدقة.

## الأمان

ينشئ Mirava نسخًا احتياطية قبل التغييرات المدعومة. التطبيق التفاعلي يحتاج إلى تأكيد، والتطبيق غير التفاعلي للمستودع يتطلب `--apply-system-repo --yes`. تحفظ النسخ في `/var/backups/mirava`.

## ✨ ما الجديد

- قائمة تفاعلية كاملة تُفتح تلقائيًا على TTY
- تثبيت تلقائي للمتطلبات الأساسية وإزالة الاعتماد على `yq`/PyYAML
- تحقق وقياس حقيقي للمستودعات باستخدام السرعة وTTFB
- قياس DNS مع التطبيق وإعادة الضبط
- اكتشاف متعدد التوزيعات وBackends آمنة
- System Overview وDoctor وCLI كامل
- توثيق بخمس لغات مع الإنجليزية كلغة أساسية
