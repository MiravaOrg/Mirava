## Обзор

Mirava — каталог программных зеркал и репозиториев пакетов для быстрого и устойчивого доступа, особенно из Ирана. Основной документ проекта — английский `README.md`; этот файл описывает новый интерфейс и использование на русском.

## Основные возможности

- Автоматическое определение Linux-дистрибутива и пакетного менеджера
- Проверка реальных метаданных репозитория до бенчмарка
- Параллельное ранжирование по скорости передачи и TTFB
- Бенчмарк и управление локальными/глобальными DNS
- Резервные копии и откат поддерживаемых изменений
- Doctor, сведения о backend-е, обзор системы/сети и неинтерактивный CLI
- Во время работы не требуются `yq` или PyYAML

## Каталог зеркал и DNS

Единый источник данных о зеркалах и DNS — [`mirrors_list.yaml`](mirrors_list.yaml). Чтобы переводы не расходились, полные таблицы зеркал остаются в основном английском README и YAML-файле.

## 🚀 Использование

### Рекомендуемый запуск

```bash
git clone https://github.com/MiravaOrg/Mirava.git
cd Mirava
chmod +x check_mirrors.sh
./check_mirrors.sh
```

Запуск `./check_mirrors.sh` без аргументов в интерактивном терминале автоматически открывает меню. В неинтерактивном режиме без аргументов выполняется проверка всех зеркал.

### Интерактивное меню

| Key | Action | Description |
| ---: | --- | --- |
| `1` | Оптимизировать репозиторий системы | Определяет дистрибутив и пакетный менеджер, проверяет совместимые репозитории, измеряет и ранжирует их, затем может применить лучший совместимый вариант после подтверждения. |
| `2` | Найти самое быстрое зеркало пакета/репозитория | Позволяет выбрать тип пакета, проверяет и измеряет подходящие зеркала. Если тип совпадает с системным репозиторием, может быть предложено применение. |
| `3` | Проверить все зеркала/пакеты | Параллельно проверяет все зарегистрированные endpoint-ы и показывает прогресс и результат. |
| `4` | Бенчмарк и управление DNS | Открывает Local/Global/All, просмотр текущего DNS, опциональное применение самой быстрой пары и сброс изменений. |
| `5` | Показать текущий DNS | Показывает текущие DNS-серверы без изменений. |
| `6` | Обзор сервера/сети | Показывает hostname, RAM/uptime, OS/архитектуру, публичный IP/локацию при наличии, DNS и активные репозитории. |
| `7` | Показать обнаруженный backend | Показывает OS, версию, codename, пакетный менеджер, семейство репозитория и поддержку auto-apply. |
| `8` | Список типов пакетов | Выводит типы пакетов/репозиториев из YAML. |
| `9` | Doctor / проверка данных | Проверяет runtime-команды, Python, backend, YAML и доступный способ повышения привилегий. |
| `0` | Выход | Закрывает меню. |

### Подменю DNS

| Key | Action |
| ---: | --- |
| `1` | Самый быстрый иранский/локальный DNS |
| `2` | Самый быстрый глобальный DNS |
| `3` | Самый быстрый DNS среди всех записей |
| `4` | Показать текущий DNS |
| `5` | Сбросить DNS-изменения Mirava |
| `0` | Назад |

### Команды CLI

```bash
./check_mirrors.sh --menu
./check_mirrors.sh --system-repo
./check_mirrors.sh --apply-system-repo --yes
./check_mirrors.sh --check-all
./check_mirrors.sh --fastest Ubuntu
./check_mirrors.sh --fastest-ubuntu
./check_mirrors.sh --dns local
./check_mirrors.sh --dns global
./check_mirrors.sh --dns all
./check_mirrors.sh --current-dns
./check_mirrors.sh --system-info
./check_mirrors.sh --backend-info
./check_mirrors.sh --doctor
./check_mirrors.sh --list-packages
./check_mirrors.sh --help
```

## Поддерживаемые backend-ы

Автоматическое применение реализовано для Ubuntu/Debian (APT), Fedora/Rocky/AlmaLinux/CentOS (DNF/YUM), Arch/Manjaro (Pacman), Alpine (APK) и openSUSE (Zypper). Для производных дистрибутивов бенчмарк может работать, но Mirava не переписывает конфигурацию автоматически, если точная схема неизвестна.

## Безопасность

Перед поддерживаемыми изменениями создаются резервные копии. Интерактивное применение требует подтверждения, а неинтерактивное изменение репозитория требует `--apply-system-repo --yes`. Резервные копии хранятся в `/var/backups/mirava`.
